📖 【おうちの方向け】3分でできるAPIキー設定

🛡️ おうちの方へ「3つの安心」
  • ✓ 完全無料・クレカ不要：Googleの無料枠を使うため、勝手に請求される心配はゼロです。
  • ✓ 設定は最初の1回だけ：端末が記憶するので次回から入力不要です。
  • ✓ 暗証番号ではありません：絵本を作る専用の合言葉（APIキー）なので安全です。
1 Google AI Studio を開く

下のボタンからGoogleの公式ページを開き、お持ちのGoogleアカウントでログインします。

👉 Google AI Studio を開く ↗

※ 初回のみ利用規約画面が出ます。「Agree（同意）」を押してください。

2 青いボタンを押してキーをコピー

① 画面上部の青いボタン 「Create API key」 を押します。

② ポップアップが出たら「Create API key in new project」を選択します。

③ 表示された AIzaSy... の横にある 「Copy」 アイコンを押します。

3 このアプリの「API設定」に貼り付け

① このガイドを閉じて、入力欄を長押し（またはタップ）。

② 「貼り付け（ペースト）」 をして 「保存する」 を押します。

③ ボタンが緑色の 「API設定済 ✓」 に変われば完了です！
